# Security boundary

MemoryLineage verifies committed history continuity, configured authorization,
and evidence replay. It does not prove semantic truth, semantic memory safety,
AI reasoning correctness, off-chain availability, or safety of an external
action.

Do not include private keys, raw private memory, or credentials in issues,
fixtures, evidence, or pull requests. Testnet deployment scripts accept keys
only through environment variables and require an explicit confirmation flag.
