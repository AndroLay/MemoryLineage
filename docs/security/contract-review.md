# Contract review notes

This is an owner-maintained source review for the pinned
`MemoryLineageRegistry.sol` artifact. It is supporting engineering evidence,
not a formal audit and not an independent auditor report.

## Review boundary

The review covers:

- registration and derived space identity;
- sequence and predecessor checks;
- transition-id and next-root derivation;
- EIP-712 domain separation;
- EOA signature parsing and low-`s` enforcement;
- ERC-1271 return-value handling;
- authorization rotation and `configNonce` binding;
- transition replay protection; and
- event fields and fixed-size storage.

The review does not cover deployment administration, key custody, RPC
availability, economic incentives, compiler correctness beyond the pinned
artifact, or arbitrary off-chain agent behavior.

## Invariants checked against source and execution

| Invariant | Source boundary | Executable evidence |
| --- | --- | --- |
| A space must be derived from its controller and salt | `registerSpace` | registration and unknown-space cases |
| A transition advances exactly one sequence | `commitTransition` | sequence gap, zero, duplicate, and parallel cases |
| A transition must extend the stored root | `commitTransition` | six stale predecessor cases |
| A changed signed field cannot reuse an old EOA signature | `hashExperienceDelta` + `_requireAuthorization` | delta/provenance/locator binding cases |
| The EIP-712 domain binds chain and contract | `domainSeparator` / `_digest` | wrong chain and wrong contract cases |
| An old authority cannot sign after rotation | `updateSpaceAuthorization` | authority-rotation lane |
| ERC-1271 must return the magic value | `_isValidERC1271Signature` | mock authorizer accept/reject lane |
| Raw memory is not a contract input or stored field | `ExperienceDelta` / storage layout | evidence privacy assertion |

The reproducible result is in
`evidence/local/security_assurance_report.json` and is regenerated by
`cargo xtask verify`.

## Explicit assumptions and residual risks

- A direct call by the configured signer with an empty signature is an
  intentional authorization path. Deployments that require every write to be
  externally signed must use a separate policy or contract wrapper.
- ERC-1271 is checked by a live contract call at execution time. A portable
  historical bundle can record on-chain acceptance, but it cannot by itself
  re-execute every historical signer state.
- The registry provides commitment lineage and authorization. It does not
  evaluate the meaning or safety of the committed memory.
- This source review is bounded by the pinned compiler artifact and test
  corpus. It does not establish that an arbitrary deployment or future draft
  has the same behavior.

No claim of “audited”, “formally verified”, “complete security”, or
“security-certified” is made by this document.
